# Personvern i Trix

Sist oppdatert 10.11.26.

Trix bruker ikke internett. Appen samler ikke inn opplysninger om deg og sender
ingenting fra maskinen din.

## Filene dine

Det du skriver og importerer, lagrer Trix i datamappen på maskinen din:

| Hvor | Mappe |
|---|---|
| Mac | `~/Library/Application Support/Trix` |
| Windows | `%APPDATA%\Trix` |
| Delt mappe | `Trix-data` ved siden av appen, hvis du har laget den |

Trix lager ingen kopi av filene andre steder. Du kan eksportere, endre og
slette dem når du vil. De blir liggende når du avinstallerer appen.

En lenke du klikker på, åpner nettleseren din. Da gjelder personvernet til
nettstedet.

## Nedlasting og oppdateringer

| Fra | Dette skjer |
|---|---|
| GitHub | GitHub behandler opplysninger om nedlastingen etter [GitHubs personvernerklæring](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) |
| Microsoft Store | Microsoft behandler opplysninger om nedlastingen og oppdateringene etter [Microsofts personvernerklæring](https://www.microsoft.com/privacy/privacystatement). Microsoft gir utvikleren samlede tall for installasjoner, bruk og krasj. Tallene viser ikke hvem du er |
